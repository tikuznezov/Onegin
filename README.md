# Onegin user manual

В данный проект предназначен для сортировки строк, полученных из текстовых файлов.
```
- Реализована собственная версия быстрой сортировки (сортировки Хоара)
- Функция чтения файла в оперативную память без промежуточной буферизации
- Функция разделения файла на отдельные строки, путем получения указателей на начала и концы строк
- Функции вывода и печати считанного текста в файл
```

Проект создан в рамках образовательного семестрового курса МФТИ ФРКТ,
под руководством [Ильи Рудольфовича Дединского](https://ded32.net.ru/).

Проект создан на операционной системе MacOS. На иных платформах возможна некорректная работа.


## Установка и запуск:
1) Скачайте архив с проектом, распакуйте в произвольную директорию.
2) Если у вас не установлен компилятор языка С++ -- g++, установите его.
5) Запустите файл Onegin.sh (для систем отличных от mac os следует самостоятельно скомпилировать файл main.cpp).
6) Запустите файл Onegin *text_input_filename* *text_output_filename*.
5) Если не указать файлы при запуске, программа попросит ввести их. В случае ошибки, завершит работу.
9) Готово!


## Описание функционала:

**Реализация быстрой сортировки:**
-> Qsort.cpp
Содержит аналог функции из стандартной библиотеки, созданный в  образовательных целях.
- Функция Qsort идентична стандартной в использовании. Работает с любыми типами данных, требует написания собственного компаратора.
- Функция Part, вызываемая функцией Qsort рекурсивно так же соответствует стандартной.


**Реализация функций чтения из файла:**
-> main.cpp
- Функция ReadFile считывает файл по указанному адресу без создания промежуточного буфера. Использует стандартные функции open, close.
В начале строки на (-1) индексе создает символ '\0' во избежание выхода за пределы буфера.
- Функция SepToStr разделяет файл на строки, записывая в структуру File массив структур с началом и концом каждой строки.
- Функция FreeFile автоматически освобождает все массивы с данными о файле и его копией из структуры File.

**Реализация собственных компараторов:**
-> main.cpp
В файле содержатся компараторы, реализованные для выполнения задания и созданные в процессе написания функции сортировки для проверки ее работоспособности.
  В задании используются:
  1) CompareStrUp   - сортировка строк в алфавитном порядке
  2) CompareStrDown - сортировка строк в алфавитном порядке начиная с конца строки
  3) Вывод оригинального текста.
  *Все сортировки не учитывают не буквенные символы и не различают заглавных и строчных символов.*


!!! В программе стоит ограничение на длину строки. Изменить ее можно в файле onegin.sh "MAX_STR_LENGTH". 
По умолчанию MAX_STR_LENGTH = 100. При превышении длинны строки могут возникать ошибки. В первую очередь, при возникновении ошибок,
следует увеличить этот параметр.
